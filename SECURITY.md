# Security

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue.

- Preferred: [open a private security advisory](https://github.com/Pray-Wall/prayer-wall/security/advisories/new) on GitHub.
- Or email **doublestrike.rar@gmail.com** with "Prayer Wall security" in the subject.

Please include what you found, how to reproduce it, and what an attacker could do with it.
Do not include the text of real prayer requests or anyone's private link.

You should get an acknowledgement within 7 days. This is a volunteer project, so fixes take as long
as they take, but anything that exposes request authors or lets content bypass moderation is treated
as urgent. You will be credited in the fix unless you prefer otherwise.

## What matters most here

- Anything that links a request to the person who posted it.
- Exposure of private link tokens, or a way to act on someone else's request.
- Ways to publish content without moderation, or to remove or bury other people's requests.
- Injection of markup or script through request text or translations.

## Supported versions

Only the version deployed from the `main` branch is supported.
